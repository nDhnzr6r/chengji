## 一页摘要

**一句话主张：把一页数据当作一次不到一秒的放映——结构先到位，数据再生长，注解最后亮起；任何一次操作都在两百毫秒内给出回声，任何一次内容替换都保留位置上的连续。**

现在的界面并不缺动效。缺的是一条总谱：页面入场、图表描边、数字滚动、进度条生长、预测点淡入各自计时，合起来从半秒到一秒三不等，观感因此散。这份计划书做五件事：

1. **统一节拍。** 全部入场动效共用 40ms 的节拍单位，页面入场分三拍，数据动画在第二拍起跑，注解在第三拍亮起；快速页面只播一拍。首屏最晚 960ms 停稳，快速页面 560ms 停稳。
2. **三拍编排。** 每个有数据的页面都按「结构 → 数据 → 注解」的顺序播放，任何时刻最多两条时间轴并行，主次相差不少于 120ms。
3. **四种强度。** 把动效分成 L0 环境、L1 反馈、L2 状态、L3 焦点四层。同一屏幕内只允许一个 L3，其余全部退到 L1 或 L2。
4. **覆盖全部交互。** 悬停、按下、焦点、展开、收起、保存、失败、撤销、删除、导入、切换，每一处都有明确、短促、可重复的反馈，不再有「点了没反应」或「整块突然出现」。
5. **可打断、可降级。** 连续操作时新动作立即接管，旧动画从当前值接续；开启「减少动态效果」后保留透明度与颜色的变化，去掉位移与缩放。

### 七个问题

**P1 入场没有总谱。** 页面入场按「第几个子元素」错峰 60ms：总览 7 个子元素，最晚 660ms；单科 4 个，540ms；详情 7 个，660ms；设置 3 个，480ms。页面之间的节奏不一致，而且错峰的单位是「直接子元素」，`main-split` 里的左右两栏共用一个延迟，跨栏的阅读顺序没有被表达出来。

**P2 两层时间轴叠在一起。** 页面层的 360ms 还没走完，图表、数字、进度条已经在自己的 0 时刻起跑，于是出现「标题还在淡入，曲线已经在画」「卡片刚出现，数字已经开始跳」的叠加。视觉上不是一条线，而是几条线同时拉。

**P3 结束时间没有上限。** 总览和单科都要到 1320ms 才完全停稳；对比 1260ms；详情 1220ms。超过一秒的入场会让用户在下一次操作前等待，且每次切换指标、范围都会重放其中一段。

**P4 同类动作参数不统一。** 面板进入有 150、220、240、300、360ms 五种；条状生长有 480、560、640、700ms 四种；淡入位移有 4px、6px、8px、12px 四种。相同的「出现」在不同组件里长得不一样，用户说不清哪里别扭，但会觉得不整齐。

**P5 切换像刷新。** 更换对比的两场考试、切换考试类型筛选、切换科目，都是整页 `innerHTML` 重建或整块内容替换。对比页换一个下拉选项，页面会重新播一遍 600ms 的入场和 1260ms 的图表；用户失去刚看完的位置。

**P6 退场普遍缺失。** 下拉、日历、筛选提示条、示例数据条、存储警告、对话框遮罩、提示条，都是瞬间消失。开场有仪式，收场没有，节奏自然断。

**P7 反馈强度平均。** 按钮按下缩到 0.985，卡片悬停只换边框颜色，表格行悬停换背景，图表入场却用 900ms 描边。轻的动作太轻，重的动作太重，屏幕里没有主次。

### 结论

需要的不是继续往每个角落塞新动画，而是三件事：

1. 一条所有场景共用的时间轴，规定每一拍谁先谁后、总共多久停。
2. 一套统一的时长、曲线、位移、错峰数值，替换现在的五种写法。
3. 把缺失的反馈补齐：退场、切换的连续性、保存与失败的确认、空态与错误的出现方式。

## 动效主张

### 一句话

**结构先到位，数据再生长，注解最后亮起；操作在两拍内回声，内容替换保留位置。**

### 三拍

每个页面的入场都拆成结构、数据、注解三段，三段的起点依次后移，允许重叠。

| 拍     | 主段      | 内容                                       | 目的                     |
| ------ | --------- | ------------------------------------------ | ------------------------ |
| 第一拍 | 0–560ms   | 页头、筛选条、指标条、卡片外框             | 告诉用户「到了哪一页」   |
| 第二拍 | 120–920ms | 曲线、条、雷达、数字                       | 告诉用户「数据是什么」   |
| 第三拍 | 560–960ms | 目标线标签、预测点、判断词、诊断句、注解段 | 告诉用户「这意味着什么」 |

三拍允许重叠：结构波收尾时数据波已经起跑，数据波进行到一半时注解波开始。重叠不改变顺序，也不允许三层同时起跑：任一时刻最多两层在推进，且后一层的起点比前一层的起点晚不少于 120ms。

快速页面（考试记录、设置）只有第一拍，560ms 内停稳。数据页面三拍齐全，960ms 内停稳。冷启动另有单独脚本，最长 800ms。

### 四种强度

| 层级 | 名称 | 用途                                   | 时长上限 | 同屏数量 |
| ---- | ---- | -------------------------------------- | -------- | -------- |
| L0   | 环境 | 背景色、边框色、分隔线、阴影的缓慢变化 | 240ms    | 不限     |
| L1   | 反馈 | 悬停、按下、焦点、选中的即时回应       | 140ms    | 不限     |
| L2   | 状态 | 展开、收起、切换、排序、加载、提示     | 320ms    | 3        |
| L3   | 焦点 | 页面入场、图表成型、主题揭示、首次导览 | 960ms    | 1        |

同一屏幕只允许一个 L3。打开对话框时，页面入场停止；打开导览时，图表不再播放；切换主题时，其他 L3 立即收束到终态。

### 不做的事

- 不给静态文案加逐字动画，不给标题加打字机效果。
- 不做视差滚动，不做整页滚动淡入，也不做逐块滚动显现。
- 不用弹跳、回弹、摇晃来表现「活泼」；`--ease-land` 只允许出现在预测点落位这一类「一次落点」上。
- 不为了展示动效而延长等待。任何超过 400ms 的动画都必须有可读的信息在同时变化。
- 不在滚动、调整窗口、切换标签页时播放装饰动画。

## 动效语言

### 时长阶梯

全部时长收敛到九档。新写的动效只能引用这些档位，不再出现 150、180、220、300、360 这样的零散值。

| 代号 | 时长 | 用途                                       |
| ---- | ---- | ------------------------------------------ |
| T1   | 90   | 按下、焦点环、颜色微变、图标位移           |
| T2   | 140  | 悬停、选项高亮、芯片选中、下划线、小段淡入 |
| T3   | 200  | 弹出层、页签切换、分段滑块、注解、数据点   |
| T4   | 240  | 容器退场、对话框面板、文字交叉、结果替换   |
| T5   | 320  | 页面层入场、面板进入、视图过渡、抽屉       |
| T6   | 400  | 数字短滚、面积淡入、表格行进入             |
| T7   | 480  | 曲线形变、条状生长、首屏数字、选中扩散     |
| T8   | 560  | 曲线首次描边、雷达、组入场                 |
| T9   | 640  | 首屏长数字、对比页首屏                     |

规则：

- 退场比入场短一档。面板进入 T5，退场 T4；提示条进入 T3，退场 T4，其中位移部分 140ms。
- 同一场景内，相邻两个动作的结束时间相差不少于 80ms，避免所有东西同时停。
- 重复播放的动效比首次短一档。首次数字 640ms，后续 400ms；首次曲线 560ms，形变 480ms。

### 缓动曲线

| 代号          | 曲线                                | 用途                           |
| ------------- | ----------------------------------- | ------------------------------ |
| `--ease-out`  | `cubic-bezier(0.22, 1, 0.36, 1)`    | 入场、数据生长、落位           |
| `--ease-soft` | `cubic-bezier(0.32, 0.72, 0, 1)`    | 颜色、混合位移、柔和的收束     |
| `--ease-in`   | `cubic-bezier(0.55, 0, 0.85, 0.36)` | 退场、收起、被替换的旧内容     |
| `--ease-swap` | `cubic-bezier(0.65, 0, 0.35, 1)`    | 位置交换、滑块移动、面板横移   |
| `--ease-land` | `cubic-bezier(0.34, 1.4, 0.64, 1)`  | 只用于「落点」：预测点、选中日 |

规则：

- 淡入配 `--ease-out`，淡出配 `--ease-in`。
- 颜色只配线性或 `--ease-soft`，不用回弹。
- 一个动效只允许一条曲线；需要两段感觉时拆成两个元素，不叠加在同一个属性上。
- `--ease-land` 的过冲幅度控制在 4% 以内，且不用于任何超过 40px 的位移。

### 位移与缩放

| 代号        | 值   | 用途                     |
| ----------- | ---- | ------------------------ |
| `--shift-1` | 2px  | 微调、提示文字、注解     |
| `--shift-2` | 4px  | 提示条、行进入、下拉选项 |
| `--shift-3` | 6px  | 页面层、卡片、面板       |
| `--shift-4` | 10px | 对话框、抽屉、空白页     |

缩放只允许三档：

- 按下 `0.98`，只用于按钮和可点击卡片。
- 弹层进入 `0.98 → 1`，只用于下拉、日历、对话框面板。
- 落点 `1.04 → 1`，只用于预测点和选中日期，时长 200ms。

### 错峰

| 代号          | 间隔 | 用途                   |
| ------------- | ---- | ---------------------- |
| `--stagger-1` | 24ms | 表格行、记录行、选项   |
| `--stagger-2` | 40ms | KPI 格、科目条、类型条 |
| `--stagger-3` | 64ms | 大区块、设置卡片       |

规则：

- 错峰只用于「一组同类元素同时出现」，不用于不同层级的元素。
- 一组错峰的总延迟不超过 240ms；超过就改为两批，第二批在第一排结束后开始。
- 同一组内，每个元素的动画时长相同，只有延迟不同。
- 连续切换时不重新错峰，全部从当前状态接续。

### 编排规则

1. **一条主时间轴。** 每次页面进入只有一个 `start` 时刻；所有延迟都相对它计算。
2. **两轴并行上限。** 同一时刻最多两条时间轴：结构一条，数据一条。注解必须等数据主段开始后再出现。
3. **主次相差 120ms。** 当前主运动的结束时间与次要运动至少相差 120ms，避免同时停。
4. **先响应，后播放。** 用户点击后 90ms 内必须有可见回应（按下态、滑块位移、选中色），入场动画随后。
5. **新动作接管。** 同一区域的新操作取消旧动画，从当前呈现值过渡到新目标；不排队，不叠加。
6. **总延迟封顶。** 结构层单个元素的延迟不超过 240ms；结构层不超过 560ms；整页入场不超过 960ms。
7. **动画不改布局。** 只使用 `transform`、`opacity`、`clip-path`、`filter`、`stroke-dashoffset`、`background-color`、`border-color`、`color`。不改 `width`、`height`、`top`、`left`、`margin`。需要改尺寸时用 `scale` 或先测量再 FLIP。
8. **终态优先。** 所有动画的默认状态就是终态；动画只负责「从起点进入终态」。脚本失败、动画被取消、用户关闭动效时，页面仍然完整可读。
9. **不阻塞输入。** 动画期间控件可点、可聚焦、可滚动；除对话框和导览外，不使用全屏拦截层。
10. **同屏一个焦点。** L3 只允许一个；播放期间其他 L3 立即收束。

## 编排架构

### 分层

```
页面
├─ 结构层 S：页头、筛选条、KPI 条、卡片外框、面板
│   └─ 入场 T5，层间 40ms，总计 ≤ 560ms
├─ 数据层 D：曲线、条、雷达、数字、表格行
│   └─ 结构层第 2 层开始后 80ms 起跑，总计 ≤ 800ms
└─ 注解层 A：目标线标签、预测点、判断词、诊断句、注解段
    └─ 结构波收尾时起跑（560ms），总计 ≤ 240ms
```

三层共享一个起点，通过 CSS 自定义属性传递序号：

```css
.enter {
  --start: 0; /* 层起点：结构 0、数据 120、注解 560 */
  --index: 0; /* 同层内第几个 */
  animation-delay: calc(var(--start) * 1ms + var(--index) * 40ms);
}
```

### 节拍器

所有层级起点与节奏点由 40ms 的节拍决定；同类元素的错峰用 24/40/64ms 三档。一个页面进入时，由 `Motion.play` 一次性写入各层的起点：

| 层   | 起点  | 说明                  |
| ---- | ----- | --------------------- |
| 结构 | 0ms   | 第 1 个元素立即开始   |
| 数据 | 120ms | 结构第二层开始后 80ms |
| 注解 | 560ms | 结构波收尾时开始      |

### 打断与重入

- **页面切换：** 默认视图过渡，320ms；旧页快照 200ms 淡出、新页快照 240ms 淡入，导航高亮在 140ms 内先到，结束后把焦点移到新页面标题。不支持视图过渡或减少动态时直接替换。
- **同区域切换：** 切换指标、范围、科目、筛选时，取消该区域的旧动画，从当前呈现值过渡。例如曲线正在从总分形变到得分率，用户又点了年级名次：从当前插值位置继续形变到新目标，不回到起点。
- **重复进入：** 用户在两秒内重复打开同一页面，第二次只播放数据段，不再播放结构层。
- **中断收尾：** 被取消的动画立即把元素置为终态，不留在中间值。

### 技术选型

| 场景           | 技术                                                                  | 原因                         | 降级                    |
| -------------- | --------------------------------------------------------------------- | ---------------------------- | ----------------------- |
| 页面与卡片入场 | CSS 动画 + 自定义属性                                                 | 声明式、可被媒体查询整体关闭 | 直接显示终态            |
| 曲线生长与形变 | SVG `stroke-dashoffset` + 逐帧插值                                    | 需要逐点时序与连续形变       | 直接画终态              |
| 数字变化       | `requestAnimationFrame` 更新文本                                      | 需要中间数值                 | 直接写终值              |
| 列表重排       | View Transitions 或 FLIP 变换                                         | 保持位置连续                 | 直接替换                |
| 对话框与弹层   | `@starting-style` + `transition-behavior: allow-discrete` + `overlay` | 原生支持顶层进出场           | 保留现有 class + 定时器 |
| 页面导航       | `document.startViewTransition`                                        | 默认路径，跨页连续           | 现有替换 + 入场         |

### 代码骨架

以下是计划中的接口形态，用现有 ES5 风格书写，不引入依赖。

```js
/* 一个页面进入：写入层级与序号，播放入场 */
Motion.play(mainEl, {
  structure: [pageHead, filterBar, kpiStrip, cardFrame],
  data: [chart, bullets, tableRows],
  annotation: [verdict, targetLine, forecast]
});

/* 同区域替换：保留外框，只换内容 */
Motion.swap(
  cardBody,
  function () {
    cardBody.innerHTML = nextHTML;
  },
  { enter: 'T5', stagger: 40 }
);

/* 数字从旧值接到新值；首次从 0 开始 */
Motion.number(el, from, to, { duration: Motion.T7 });

/* 打断：同一 key 的新播放取消旧播放，并从当前值接续 */
Motion.interrupt('trend', function () {
  chart.set(points, { animate: true });
});

/* 反馈：按下、保存、失败、撤销 */
Motion.feedback(btn, 'press');
Motion.feedback(input, 'saved');
Motion.feedback(field, 'error');
```

## 场景分镜

每个场景一张时间线表。时刻从该场景的起点算起，单位毫秒。同一行内的多个对象共用一个起始时刻。层级起点由 40ms 的节拍决定，同类元素的错峰用 24/40/64ms 三档，其余时长都落在 T1–T9。

## 可访问性

### 减少动态效果

现在的做法是全局 `animation-duration: 0.001ms` 与 `transition-duration: 0.001ms`。这会让所有过渡瞬间跳到终态，包括本应保留的颜色变化，也会让依赖 `transitionend` 的逻辑失去事件。新方案按性质分别处理：

| 动效类型                 | 减少动态时的处理          |
| ------------------------ | ------------------------- |
| 位移、缩放、旋转         | 全部去掉，元素直接在终位  |
| 透明度、颜色、边框、阴影 | 保留，时长缩短到 90–140ms |
| 曲线描边、条状生长       | 直接呈现终态              |
| 数字滚动                 | 直接写终值                |
| 遮罩、对话框、提示条     | 只保留 90ms 透明度        |
| 启动遮罩                 | 直接跳过                  |
| 导览                     | 直接定位，只保留淡入      |
| 列表重排                 | 直接替换，不补间          |

实现原则：

- 每个动画规则默认写在 `@media (prefers-reduced-motion: no-preference)` 内，或提供 `reduce` 覆盖；两种写法在同一段代码里，不散落在文件各处。
- 只对承载意义的动效做例外：保存成功的绿边、错误红边、提示条出现，在减少动态下仍然保留透明度变化。
- 不隐藏内容：动画被取消时元素仍在终态，不依赖 `animation-fill-mode` 才能看见。

### 焦点与顺序

- 页面切换后，把焦点移到新页面的一级标题（`tabindex="-1"`），键盘用户不会停在已移除的链接上。
- 对话框打开时聚焦第一个可编辑字段；关闭后把焦点还给触发按钮。
- 下拉与日历关闭后焦点回到触发按钮；方向键在选项之间移动时，高亮项 90ms 内可见。
- 导览每一步把焦点限制在气泡内，退出后还给页面。

### 信息不依赖动效

- 所有涨跌、达标、错误都有文字或颜色表达，动效只是强调。
- 图表末点与预测点即使不播放动画也有标签。
- 条状图的目标刻度始终可见，不靠在动画结束时才出现。
- 状态标签（`kpi-state`）在动画期间就存在于 DOM，读屏可以立即读到。

### 闪烁与自动播放

- 不使用闪烁、频闪、快速切换亮暗的动效。
- 没有自动轮播、自动滚动、装饰性循环动画；导入读取时的进度条只在读取期间出现，完成即停止。
- 导览只在首次进入时出现，可跳过。
- 提示条停留时间足够阅读，带动作时 7 秒；指针停在上面时倒计时暂停。

### 键盘与触屏

- 所有按下态在键盘触发时同样出现（`:active` 与 `:focus-visible` 分开处理）。
- 触屏不显示行的左侧标记，按下反馈只用背景色与 0.98 缩放，避免滑动时误闪。
- 抽屉、对话框、弹层都支持 Esc 关闭，关闭动画不阻止键盘操作。

## 性能预算

### 帧预算

| 项目             | 预算                                                        |
| ---------------- | ----------------------------------------------------------- |
| 单帧脚本时间     | 小于 8ms                                                    |
| 单次动画元素数量 | 不超过 60 个                                                |
| 同时运行的动画   | 不超过 3 条时间轴                                           |
| 单帧重排         | 0 次（动画期间不读 `offsetWidth`、`getBoundingClientRect`） |
| 长任务           | 无超过 50ms 的任务                                          |
| 图表点数         | 不超过 40 个点                                              |
| 入场总时长       | 首屏 960ms，快速页 560ms                                    |
| 重复操作响应     | 90ms 内出现可见反馈                                         |

### 属性白名单

允许动画的属性：

```
transform、translate、scale、rotate、opacity、clip-path、
stroke-dashoffset、stroke-width、background-color、border-color、
color、box-shadow、filter（仅限小面积）、visibility、
grid-template-rows（仅折叠区）
```

禁止动画的属性：

```
width、height、top、left、right、bottom、margin、padding、
font-size、line-height、grid-template-columns、flex-basis
```

需要尺寸变化时，用 `scale` 表达，或先测量再用 FLIP 变换；折叠区用 `grid-template-rows: 0fr → 1fr` 过渡，不逐帧改高度。

### 合成与内存

- 动画期间才加 `will-change`，结束后移除，避免长期占用图层。
- 曲线形变复用同一组 SVG 节点，不每帧创建元素。
- 数字滚动每帧只写一次 `textContent`，不触发样式重算之外的读取。
- 列表替换时先构建片段再一次性插入，避免逐行触发布局。
- 导览的高亮框用 `box-shadow` 铺满遮罩，不创建大面积半透明层。

### 测量方法

- Chrome DevTools Performance 录制每次页面进入，检查主线程无长任务、无连续布局。
- 用 `PerformanceObserver` 记录 `long-animation-frame`，阈值 50ms。
- 在 1440、1180、1040 三个宽度和深浅两套主题下各测一次。
- 连续切换指标 20 次，检查内存不增长、动画实例不累积。

## 实施顺序

### P0 基础与反馈（54 项）

**目标：** 建立 token 与播放器，替换页面入场，补齐按钮、链接、卡片、焦点、行悬停的反馈。

- 页面入场从 `nth-child` 延迟改为「层 + 序号」。
- 按钮、链接、图标按钮、卡片、导航、页签、芯片、输入框的悬停、按下、焦点统一到 T1/T2。
- 减少动态的按性质处理替换全局 0.001ms。

**验收：** 任一页面进入的总时长符合 6.2 的时间线；悬停与按下在 140ms 内可见；减少动态下颜色仍变化。

### P1 数据动画（35 项）

**目标：** 曲线、条、雷达、数字统一节奏。

- 曲线描边 560ms、形变 480ms、点数错峰 24ms、预测段 640ms 起。
- 条状生长 480ms、错峰 40ms。
- 雷达 640ms、层错峰 80ms。
- 数字首次 640ms、后续 400ms，位置与精度不变。
- 图表悬停统一到 140ms。

**验收：** 总览与对比在 960ms 内停稳；切换指标连续形变；连续切换 10 次无叠加。

### P2 切换与连续（20 项）

**目标：** 换页、换科目、换指标、换对比、筛选都保留位置，不整页重播。

- 对比更换不重建选择器。
- 筛选先退后进。
- 列表重排使用视图过渡或 FLIP。
- 交换先后用镜像位移。

**验收：** 对比页换组合不闪整页；单科切科目时外框不动；筛选后滚动位置合理。

### P3 覆盖层（25 项）

**目标：** 对话框、下拉、日历、提示条都有进有出。

- 对话框：遮罩 200ms、面板 240ms、关闭 200/140ms。
- 下拉与日历：打开 200ms、关闭 140ms、翻页有方向。
- 提示条：进入 200ms、退场 140ms、进度线，悬停暂停。
- 优先使用 `@starting-style` 与 `allow-discrete`，保留 class 回退。

**验收：** 所有覆盖层都有退场；顶层元素不被裁切；快速开关 10 次无残留。

### P4 细节与主题（54 项）

**目标：** 设置页、保存反馈、错误、空态、导入导出、主题、启动、响应式。

- 保存成功绿边与失败抖动。
- 折叠区、类型芯片、配色卡片。
- 空态逐层出现。
